## Getting Started
1. Install a compatible JDK and the build tool used by the project.
2. Clone the repository:
   ```bash
   git clone https://github.com/MahiTzy/examportal-backend-springboot.git
   cd examportal-backend-springboot
   ```
3. Review the build file and application configuration.
4. Configure the required database and any external services using local settings.
5. Run with the Maven wrapper if available (`./mvnw spring-boot:run`) or the configured build tool.
